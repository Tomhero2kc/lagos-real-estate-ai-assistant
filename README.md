# Lagos Real Estate AI Assistant

This is the final project in my Lagos real estate learning series.

I am building a simple app that brings together the rent prediction work from my previous project with a tenancy information assistant.

The idea is to let someone enter basic property details, get an estimated annual rent and ask general questions about renting in Lagos from one place.

## What I Plan to Build

- A simple Streamlit interface
- Lagos rent estimation
- A tenancy information section
- A combined property advice feature
- Clear error messages
- Basic testing
- Screenshots showing the finished app

## Current Progress

The repository is set up. My next step is to build the first version of the user interface.

## Note

This is a learning project. Rent estimates are based on practice data, and the tenancy information should not be treated as legal advice.
